# MINI WORLD TYCOON

A mobile 3D shop-management tycoon prototype built with Godot 4.

## Current milestone

**Milestone 0 — project scaffold**
- Godot 4 project configuration
- First 3D scene with a lit floor and camera
- Mobile-friendly Compatibility renderer

This is only a starter scene, not a completed or tested game build.

## Open on Android

1. Download this repository as a ZIP from GitHub.
2. Extract the ZIP into a folder on the phone.
3. Open Godot Android Editor.
4. Import the extracted folder as an existing project by selecting its `project.godot`.
5. Open the project and run the main scene.

## Planned MVP

1. Shop environment and camera
2. Player character and touch controls
3. Shelves and stockable products
4. Customer navigation and shopping
5. Checkout and in-game currency
6. Upgrades and local save data

Target: Android first, iOS later.
